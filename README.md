Grocery Price Tracker Canada

***Requirments***
stats-can: https://pypi.org/project/stats-can/
matplotlib
pandas
py3_wget


Running main.py downloades data.zip, and opens a csv file in order to parse data. A tkinter gui window will open prompting to select A region (canada or a specific province), a retail product and a duration.
Chooisng a diration of one month will simply display the average price of the retail product in that region for the most recent month, while choosing a longer durtion will plot a graph
showing the average monthly price over the diration that was selected.
